MosaicUI

Introduction

Welcome to MosaicUI, a free and open-source collection of high-quality React components built with Tailwind CSS and Motion. These components are designed for modern React applications.

How It Helps

We believe UI components should be flexible, not restrictive. Our components are built around four core pillars:

Fully Customizable

Built with Tailwind CSS so you can easily adapt styles and layouts to match your design system.

Modern React Practices

Uses clean architecture and reusable patterns inspired by modern React development.

Performance First

Lightweight components with optimized rendering and smooth Motion animations.

Accessibility (A11y)

Built with keyboard navigation, focus states, and screen reader support in mind.
