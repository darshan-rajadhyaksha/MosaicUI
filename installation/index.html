MosaicUI

Installation

Follow these simple steps to add MosaicUI components to your React project.

Prerequisites

Make sure you have Tailwind CSS (v4), Motion, clsx and tailwind-merge installed in your project.

Terminal / Console 
npm install tailwindcss motion clsx tailwind-merge

Add the utility function cn inside your utils folder.

/utils/cn.ts 
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

const cn = (...inputs: ClassValue[]) => {
  return twMerge(clsx(inputs));
};

export default cn;

Steps

1. Choose a Component

Browse the components library and select the component you want to use.

2. Install Dependencies

Some components may require additional external dependencies. Install them before use.

3. Copy Component Code

Copy the component source code into your project. You can modify it freely to fit your needs.

4. Use the Component

Import and use the component in your project. Check the Props section for available customization options.
