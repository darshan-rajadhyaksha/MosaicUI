| Prop            | Type                                                                 | Required | Default                     | Description                                                                |
|-----------------|----------------------------------------------------------------------|----------|-----------------------------|----------------------------------------------------------------------------|
| className       | `string`                                                             | No       | —                           | Additional CSS classes applied to the root container.                      |
| size            | `number`                                                             | No       | `10`                        | Size of each grid cell in pixels. Range: **10 – 100**.                     |
| speed           | `number`                                                             | No       | `1`                         | Animation speed multiplier. Range: **0 – 5**. `0` disables movement.       |
| strokeColor     | `string`                                                             | No       | `"rgba(127, 127, 127, 0.5)"` | Color of the grid lines. Accepts any valid CSS color value.             |
| direction       | `"top" \| "bottom" \| "left" \| "right" \| "top-left" \| "top-right" \| "bottom-left" \| "bottom-right"` | No | `"top"` | Direction in which the grid animation moves.                      |
