| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| children | `React.ReactNode` | Yes | — | One or more `FloatingActionMenuItem` components to display in the menu. |
| radius | `number` | No | `640` | Radius of the imaginary circle used to position menu items. A larger radius creates a flatter arc, while a smaller radius creates a more curved layout. Adjust this based on the number of menu items and the desired curvature. |
| gap | `number` | No | `4` | Angular gap (in degrees) between adjacent menu items. Increase the gap to spread items farther apart or decrease it to make the menu more compact. Tune this according to the number of menu items. |
| className | `string` | No | — | Additional CSS classes applied to the menu container. |
| actionButtonClassName | `string` | No | — | Additional CSS classes applied to the floating action button. |
