| Prop | Type | Required | Default | Description |
| ---- | ---- | :------: | ------- | ----------- |
| children | `React.ReactNode` | Yes | — | The content to render inside the carousel item. |
| className | `string` | No | — | Additional CSS classes applied to the carousel item. |
| style | `React.CSSProperties` | No | — | Inline styles applied directly to the carousel item. |
